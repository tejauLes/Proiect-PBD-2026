# SportClub Manager - Proiect Baze de Date

* **Student:** Tămășan Bogdan
* **Universitatea:** UTCN - Centrul Universitar Nord din Baia Mare (CUNBM)
* **Facultatea:** Inginerie, Domeniul Calculatoare
* **Disciplina:** Proiectarea Bazelor de Date

## 1. Scop și Obiectiv

* **Domeniu:** Gestiunea activității dintr-un club sportiv („SportClub Manager”).
* **Problemă concretă:** Urmărirea prezențelor la antrenamente, gestionarea evidenței financiare (cotizații/abonamente), planificarea resurselor și evaluarea sportivilor.
* **Utilitate practică:** Centralizarea datelor, automatizarea validării plăților și integrarea unui flux de analiză predictivă cu Inteligență Artificială.
